Display

Built-in display

Used unless the program starts with a -- display: <file> line. Assert these relations to draw icons.

icon T
Draw a box for the term T.
icon:name T N
Label icon T with N instead of T itself.
at X L
Nest icon X inside icon L. Both must be icons. An icon with several at parents appears in each one, and a cycle of ats is dropped with a warning. With #agg at * -> last, only the latest location counts.
left:right A B
Put A in a column left of B. Both must share a parent (top-level icons count).
above:below A B
Put A in a row above B. Both must share a parent (top-level icons count).

When rows show

A row counts only if its interval contains the moment being viewed: the selected choice while one is pending, otherwise the end of the program. Use ^ or ~ for things that change over time, and + for things that last.

Choices

While a choice is pending, the strip above the display lists each choice with its possible values; click a value to pick it. Clicking a row selects that choice, and the display is drawn at the moment it was asked. Clicking an icon whose term is a valid option for the selected choice also picks it. If it fits more than one slot, the icon turns dashed. Then click the slot you mean in the strip.

Example

+ icon board, + icon hand
+ icon c1, + icon:name c1 ace, + at c1 hand
+ icon c2, + at c2 hand
+ left:right c1 c2
+ above:below board hand
